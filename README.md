# place-id-finder
Find Place ID (Google Place API) from address, business name and coordinates

## Steps:
 1. Copy the "Payment Locations" folder ("...\DCE TDS\CE.Content\sitecore\content\Configuration\Component Locations\Locations\Payment Locations") in the same directory as this script.
 2. Set your Google Maps API key in the .env file.
 3. Set the referrer in the .env file.
 4. Create a virtual environment and install the required packages.
 5. Run this script.
 6. Replace the TDS items with the result in the folder "Payment Locations - Results"
